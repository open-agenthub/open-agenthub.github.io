03 / MAKE IT YOURS

Your cluster.
Your starting point.

Already running Kubernetes? Deploy with Helm. Getting started locally? The quickstart provisions a single-node cluster.

EXISTING KUBERNETES CLUSTER

Deploy with Helm

helm repo add agenthub \
  https://open-agenthub.github.io/open-agenthub
helm install agenthub agenthub/open-agenthub \
  -n agenthub --create-namespace \
  --set postgres.password="$(openssl rand -hex 16)"

Keep the generated database password for upgrades. Follow the guide to configure storage, access and authentication.

Read the deployment guide ↗
NO CLUSTER YET

Use the local quickstart

Linux uses k3s. macOS and Windows use k3d with Docker Desktop. The installer includes persistent Postgres and object storage.

Linux / macOS
curl -fsSL https://open-agenthub.github.io/install.sh | sh
Windows PowerShell
iwr -useb https://open-agenthub.github.io/install.ps1 | iex

Recommended starting resources: 4 vCPU · 6 GB RAM. Requirements grow with your workloads.

From version 1.5.0, installs without OIDC require a shared admin API key. Use HTTPS when exposing your instance; configure OIDC for individual identities. Read the setup guide and upgrade instructions. Infrastructure and model-provider usage are separate costs.

05 / BEFORE YOU DEPLOY

Good questions.
Clear answers.

Do I need to know Kubernetes?

Open AgentHub runs on Kubernetes. The quickstart can create a local cluster for you, but you still operate the deployment. If you already manage a cluster, use the Helm chart.

Does self-hosting keep all model data local?

No. The agent workspace runs on your infrastructure, but prompts and other model inputs can still go to your chosen provider. Check the provider's data policies for your use case.

What does session isolation cover?

Each session runs in its own pod with selected credentials and network policies. Containers share the host kernel unless you configure an additional runtime boundary. Isolation does not replace careful credential scoping.

Can I build a ticket-to-agent workflow?

Yes, using the API, MCP tools and session messaging. You build the integration, handoffs and review gates. Open AgentHub is not a preconfigured service-desk automation product.

Can I try a hosted demo?

There is currently no hosted trial. Start with the local quickstart or deploy to your cluster. The getting-started guide walks through setup.
