Feature overview ​

Every user-facing feature of Open AgentHub, the edition it belongs to, who can use it, and the page that explains it. It describes release 1.14.1.

Community features are free and open source (AGPL-3.0) and need no licence. Enterprise features live under ee/ in the repository and need a valid licence; without one they are switched off and everything else keeps working.

Roles used on these pages:

RoleWho
OwnerThe person who created the session or project
CollaboratorSomeone a session is shared with who may type into it (Enterprise)
ViewerSomeone a session is shared with who may only watch (Enterprise)
AdminAn AgentHub administrator
OperatorWhoever installs and configures the Helm chart
