Where to start ​

If you have a cluster, go to Install. If you are upgrading an existing release, read Upgrading first — there is one Helm pitfall that bites almost everyone.

New here? The feature overview lists every feature, its edition and the page that explains it. To learn the daily work, start with Sessions, Projects, the Workspace and Questions and approvals.

The most common setup tasks after installing:

  • Chat integrations — get session updates and approve permissions from your phone.
  • Git integrations — let sessions clone and push without a manual token.
  • Provider login — sign in to your agent's provider from a session.
  • Continue locally — take Claude Code or Codex history to your workstation.
  • MCP clients — connect external clients over HTTP or stdio.
  • Auto approve — let a session run its tools without asking.

Editions ​

The core is AGPL-3.0. Enterprise features live under ee/ in the repository and need a valid license: session and project sharing, Slack, org-wide usage limits, groups and roles from your identity provider, allowed agent kinds, and sharing MCP servers and skills with others. Telegram and Signal are part of the free core. Without a licence the Enterprise features are switched off and everything else keeps working.
